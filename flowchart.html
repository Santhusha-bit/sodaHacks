DigiGuide

Accessibility Road-Crossing Assistant for Blind & Deaf Pedestrians
Version: 1.0
Date: 2026-03-07
Status: DRAFT
1 · Overview

Purpose

DigiGuide uses embedded computer vision and cloud AI to give real-time street-crossing guidance to users who are blind (via audio) or deaf (via haptic + screen alerts).

Scope

ESP32 S3 Box 3 firmware, a Python orchestration backend, Gemini Vision API integration, ElevenLabs TTS, piezoelectric haptic output, and a Three.js companion UI.

User Modes

Blind: Audio narration of scene context via ElevenLabs TTS.
Deaf: Haptic buzzes + on-device screen warnings.

Key Constraint

Latency target <2 s from camera capture to output alert. Hazard priority ordered by: person > vehicle > cyclist > other.

3 · Component Descriptions
Component Type Role Interface / Notes
ESP32-CAM Hardware Captures continuous JPEG frames of the street scene at ~5 fps. Streams over Serial/WiFi to S3 Box 3; 320×240 JPEG sent per inference cycle.
ESP32 S3 Box 3 Hardware Central controller. Routes sensor data to Python backend and renders deaf alerts on its built-in display. WiFi client to Python server; ILI9342C LCD for screen output; GPIO for piezo PWM signal.
PIR Distance Sensor Hardware Measures proximity of detected objects (e.g. 10 ft). Used to determine haptic buzz intensity. GPIO analog/digital read on S3 Box. Distance merged with Gemini object list.
Piezoelectric Disk Hardware Provides haptic vibration feedback for deaf users. Buzz frequency inversely proportional to hazard distance. Driven by PWM signal from S3 Box GPIO; intensity mapped [0–255] from distance value.
Python Backend Software Orchestrates the full pipeline: receives frames, calls Gemini, builds precedence array, routes to correct output path. Flask/asyncio server. Precedence array: [{label, distance, priority}] sorted by severity.
Gemini Vision API Cloud API Classifies objects in each JPEG frame (cars, people, cyclists, traffic lights, etc.) and returns spatial context as JSON. Called via gemini-2.0-flash. Prompt instructs model to return JSON list of detected objects with spatial tags.
ElevenLabs TTS Cloud API Converts the highest-priority hazard description string into natural speech MP3 streamed to device speaker. REST API; voice ID configurable. Example output: "Car approaching from your left, approximately 10 feet."
Selenium Agent Cloud API Browser automation layer. Handles web-based signal lookups (e.g. live traffic API, crosswalk state polling). Headless Chrome; results fed back into precedence array for additional context enrichment.
Three.js UI Software Companion web interface. Glowing orb pulses in sync with ElevenLabs audio (blind) or flashes red with proximity (deaf). ShaderMaterial + Perlin noise for orb effect. Receives alerts via WebSocket from Python backend.

5 · Key Data Structures & Latency Budget
Precedence Array schema: [ { "label": "car", "direction": "left", "distance_ft": 10, "priority": 1 }, ... ] Sorted ascending by priority. Priority 1 = imminent danger.  |  Latency budget: Camera capture → Gemini (~800 ms) → TTS/haptic dispatch (~400 ms) → output → <2 s total.
